\begin{abstract}
As cloud quantum computing tools become increasingly dependent on deep Python dependency graphs, verifying fundamental hardware executions without heavy runtime overhead has become challenging. We introduce \texttt{SCS-Quantum}, an open-source, dual-layer verification engine designed for high-reproducibility experiments on superconducting quantum processors. Built with a zero-dependency Python core and an accompanying high-performance Rust implementation, \texttt{SCS-Quantum} encodes frequency-domain wave packet parameters $(A, f, \phi)$ into transmon registers and executes direct hardware validation via IBM Quantum primitives~\cite{cross2018qiskit,heron2024}. We report validation benchmarks across 7 independent hardware runs ($>14{,}000$ execution shots) on the 156-qubit IBM Heron processor (\texttt{ibm\_marrakesh})~\cite{heron2024,blais_cqed}, demonstrating consistent Bell-state balance between $87.7\%$ and $99.3\%$ (median $94.9\%$) alongside complete three-qubit GHZ state synthesis. The package provides native AST dependency audits, rigorous evidence-level separation, and deterministic offline simulation testbeds, providing an accessible baseline for quantum software verification.
\end{abstract}

\section{Motivation and Significance}
Cloud-hosted quantum experimental frameworks typically mandate extensive software environments with dozens of transitive dependencies~\cite{cross2018qiskit,cirq2021,bergholm2018pennylane}. This introduces dependency rot, non-deterministic package resolution, and barriers to long-term reproducibility. 

\texttt{SCS-Quantum} resolves these challenges by decoupling the mathematical state encoding and verification logic from provider-specific SDK bindings. The core encoding and decoding logic is implemented with zero third-party dependencies in standard Python (audited via abstract syntax tree inspection) alongside a high-performance native Rust crate~\cite{matsakis2014rust}.

\section{Software Architecture and Functionalities}
The repository is structured into modular verification tiers:
\begin{enumerate}
  \item \textbf{Core Mathematical Encoding:} Parameterizes a continuous wave-packet $\psi(t) = A \exp(-\gamma t) \cos(2\pi f t + \phi)$ into parameterized single-qubit rotations ($R_Y, R_Z$) and entangling CNOT sequences~\cite{nielsen_chuang,krantz_guide}.
  \item \textbf{Dual Language Equivalence:} Features a native Rust library implementing the same state parameterization, verified against the Python implementation via automated unit tests.
  \item \textbf{Lightweight QPU Interface (\texttt{tkr\_ibm}):} Provides a streamlined, self-contained driver interfacing directly with IBM Runtime \texttt{SamplerV2}~\cite{cross2018qiskit,heron2024}, abstracting transpilation and shot-retrieval into declarative CLI commands.
  \item \textbf{Built-in Self-Testing & AST Audits:} Enforces a strict static inspection rule verifying that offline verification scripts contain zero external package imports.
\end{enumerate}
